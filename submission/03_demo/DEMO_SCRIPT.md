# TRUST//INTERCEPT — 3-Minute Demo Script

> **Runtime:** This is the live hosted demo path. The Vercel frontend calls the deployed FastAPI backend, which uses a real configured LLM provider. Offline mode is only the emergency fallback.

## 0:00–0:20 — Problem
“Scams don't need to steal your money first. They need to control your next decision. This parcel message is trying to make the user click, pay and trust the sender before verifying anything.”

## 0:20–0:45 — Intake
Paste the parcel SMS into TRUST//INTERCEPT.
Show PII redaction and the extracted evidence.
Say: “The message is evidence, not instructions. The system will not obey commands embedded inside it.”

## 0:45–1:15 — Investigation
Open the Manipulation Graph.
Show urgency, impersonation and requested payment.
Open the Adversarial Evidence Arena.
Explain Hunter, Skeptic and Verifier in one sentence each.

## 1:15–1:45 — Verification
Open Counterfactual Verification.
Say: “If this were legitimate, what independent evidence should exist?”
Show the safe verification path.
Emphasise: “We do not open the suspicious destination.”

## 1:45–2:10 — Decision Defence
Show VERIFY / PAUSE / REPORT.
Pause at the Human Approval Gate.
Say: “The system recommends; the person remains in control.”

## 2:10–2:35 — Auditability
Open Evidence Passport and Case Replay.
Show provenance, evidence fingerprints and the read-only replay.

## 2:35–2:55 — Immunity
Open the adaptive coach.
Answer the micro-challenge.
Say: “The incident becomes targeted training for the next attempt.”

## 2:55–3:00 — Close
“Other systems can tell you something looks suspicious. TRUST//INTERCEPT protects the decision that happens next.”
